# #SYSTEMATIZE:CUTTING — Распределение целевой переменной и признаки
>[!quote] Target distribution and features

## #ALIGN:A — Цель этапа
Понять, как устроена целевая переменная (прогресс диабета) и как с ней связаны
исходные признаки.

## #ALIGN:L — Условия (ЧТО ДАНО?)
- **Датасет**: diabetes dataset (sklearn), 442 пациента.
- **Признаки (10)**: age, sex, bmi, bp, s1–s6 (нормализованные, среднее 0, дисперсия 1).
- **Целевая переменная `target`**: количественная мера прогресса заболевания
  через год после baseline (значения ~25–350).
- **Задача**: регрессия (предсказание target), вспомогательно – кластеризация.
- **Предположения**: данные без пропусков, все признаки числовые, мультиколлинеарность
  возможна (s1–s6 — сывороточные показатели).

## #DEEP[ТЗ -> theory]:CUTTING
### Математическая основа
- **Гистограмма** — непараметрическая оценка плотности кусочно-постоянными блоками.
  Число корзин (bins) управляет компромиссом между смещением и дисперсией.
- **KDE (Kernel Density Estimation)** — ядерная оценка плотности:
  $$\hat{f}(x) = \frac{1}{nh}\sum_{i=1}^{n}K\!\left(\frac{x-x_i}{h}\right)$$
  где $K$ — ядро (обычно гауссово), $h$ — ширина окна. Позволяет увидеть
  моду, асимметрию, унимодальность/бимодальность.
- **Корреляция Пирсона**: $r = \frac{\text{cov}(X,Y)}{\sigma_X \sigma_Y}$ измеряет
  линейную связь. Полезна для первичного отбора признаков.
- **Scatter plot** — визуализация совместного распределения двух переменных,
  выявляет нелинейность и гетероскедастичность.

## #DEEP[theory -> context]:CUTTING
### Медицинская интерпретация
- Гистограмма + KDE показывают **разнообразие течения диабета**:
  - Узкий симметричный пик → большинство пациентов ухудшаются примерно одинаково.
  - Правый хвост (положительная асимметрия) → есть подгруппа с быстрым прогрессом.
  - Бимодальность → возможно, две разные траектории болезни.
- **Корреляция с target**: признаки bmi, bp, s5 обычно показывают наивысшие
  коэффициенты. Высокий BMI → ожирение, ускоряет диабет; s5 (возможно, триглицериды)
  — маркер метаболического синдрома.
- **Scatter**‑ы выявляют **нелинейные эффекты**: например, связь возраста и
  прогресса может быть U‑образной (молодые и пожилые более уязвимы?).
  Это уже повод для полиномиальной регрессии.
